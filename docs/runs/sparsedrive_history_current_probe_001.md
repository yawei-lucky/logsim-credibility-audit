## 新得到的诊断

1. **当前图片不能单独解释输出。** RR 与 SR 的当前图片逐字节相同，历史不同，
   仍留下约 `8.3 cm` 端点前向差。不能用当前单帧相近推断时序接收方输出相近。
2. **历史也不能单独解释输出。** 同真实前缀，当前换成仿真图片产生约
   `27.6 cm` 端点前向差。当前输入的影响有明确支撑。
3. **不能把两者当作独立可相加的固定偏置。** 相加预测第四格的残差超出
   事前传播的数值包络。候选“当前决定全部”“历史决定全部”“来源效应相加”
   均在该有限合同内为 `rejected`；三个作用诊断为 `accepted`。

这是固定接收方对组合输入的实测，不是另写一个具有预期行为的合成控制器。
候选和交互公式仍由研究者给定，没有自动学出新的物理规律或完备字典。

## 配对核验与现实证据边界

48 张真实 JPEG 来自已有官方样本成员，SHA-256、成员 CRC／长度及完整解码
通过；48 张仿真 PNG 与归档生成报告、帧号、metadata 哈希及原生动态保留记录
一致。两种输入的声明相机记录除图片路径外相同。没有再下载数据或修改图片。

但两份相机记录不能直接混同：对齐首帧前相机 gauge 后，所选初始／优化位姿
最大记录差约 `0.763265 m`、`0.377373°`。这不是实际相机误差估计。
原始 nuScenes 身份、ASAP／标定对应、初始位姿与优化重建坐标的物理配对、
checkpoint 训练划分和外部任务误差界仍不足。Source Availability Gate 未通过，
不把当前 S 输入称为已资格化的物理同位姿现实副本。

来源切换是诊断干预，可能包含混合输入的分布影响。结果没有隔离检测缓存、
地图缓存、运动历史队列或某种视觉缺陷，不能归因到单一组件；也没有测物理
延迟、恢复记忆需要几帧、规划是否正确、碰撞或真实闭环后果。
旧完整 native 状态逐元素复现失败的裁决保留。本轮只要求其有限性及最终计划
数值控制，不据此恢复那条旧主张。
