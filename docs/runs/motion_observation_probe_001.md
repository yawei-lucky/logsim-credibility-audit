# HUGSIM 运动成像标靶实验 001

2026-10-11。**已实际完成 GPU 渲染和 RGB 测量，整体为 `down-weighted`。**
在本轮人工标靶合同内，运动、距离偏差、信息年龄和尺度变化的图像后果符合预先
写出的关系；这为测量工具和 HUGSIM 渲染路径提供了有限正面证据。同时确认了
一个指标盲区：只测图像增长率会漏掉恒定尺度偏差，且在当前误差预算下对部分
距离/时间偏差不够敏感。

这是验证基线与测量资格实验，不是新的物理理论，也不验证车辆重建质量或现实
驾驶正确性。采用已知标靶正是为了不把旧车框或 Gaussian 包络当成轮廓真值。

## 借鉴的验证做法

[NVIDIA／理想联名报告](https://docs.nvidia.com/nurec/best-practices/scaling-neural-reconstruction.html)
将固定轨迹渲染检查、真实日志与重建输入的下游比较、重仿真行为比较，以及
时间/预处理/确定性列为相互关联的验证工作。
[NuRec validation 使用说明](https://docs.nvidia.com/nurec/nurec/run-validation.html)
主要检查重建产物，并要求结合图像检查局部问题。上述是作者报告的实践，不能
据此推断公开系统已获得独立的现实等效证明。

结合当前仓库，适合我们的实验顺序如下。这是本项目的选择，不是照搬其工业流程。

| 我们可执行的实验 | 可以回答的问题 | 本轮状态 |
|---|---|---|
| 固定相机、已知标靶、已知运动、重复渲染 | 状态变化是否传成可预测的 RGB 信息；测量器能否识别已知偏差 | 已执行，见下文 |
| 非等深、转动、遮挡的失效对照 | 简化宽度模型在哪些前提失效；分析器何时应停止给数值 | 后续已执行，见[适用边界实验 001](motion_observation_boundary_001.md) |
| 复用已有 matched factual 窗口，分离位姿误差与局部重建误差 | 已观察到的真实—仿真差异分别由什么引起 | 后续候选，需保留来源门与匹配合同 |
| 有真实依据的近停/倒车/轨迹跟踪对照 | 控制—状态差异是否妨碍解释闭环后果 | 后续候选，先建立车辆合同；不能套用别家的误差阈值 |

AD 部分暂不扩展；若后续恢复接收方比较，直接承接已有
[matched factual audit](sparsedrive_real_sim_factual_001.md)，固定模型、历史和输入
合同，再讨论与图像差异的关系。当前不扩到大规模事件复现率或全量 benchmark。

实验调用 HUGSIM `Camera → render → gsplat → RGB`，两种背景分别为空背景和已有
scene-0383 静态重建。后者保留其 affine 颜色变换、地面和背景。相机固定在原
metadata 首帧 CAM_FRONT 位姿，分辨率 800×450，`fx=633.2086015 px`。
原生动态车辆未参与；双标记经 HUGSIM 的目标位姿变换接口渲染。

两特征中心间距 1.6 m、球形 Gaussian 标准差 0.035 m、等深且姿态固定。同一几何
分别渲染亮/暗两个版本，从原始 RGB 差分中的两个连通域计算质心间距。测量器
不读取投影坐标、semantic、depth 或 renderer 的 `means2d`。

每种背景均有 3 条轨迹 × 6 种条件 × 9 个时刻，共 **324 个主测量图对**；另有
18 个重复图对，总计 **684 张新 RGB 渲染**。它们是设计网格，不能当作 324 个
独立道路样本。运行于北京时间 13:19，已结束，没有后台实验进程。

## 旧片段筛查与测量资格

CF-M nominal 的前 2 秒保存了 9 个 RGB/状态对，逻辑时间间隔均为 0.25 秒，
保存状态的相对 yaw 变化为 0。人工查看图像时，目标在前方且没有明显外部遮挡。
但车灯/车身特征缺少独立三维坐标与尺寸，表面等深资格也未建立；因此本轮没有
用它估计物理距离或延迟。逻辑状态时间也不能替代曝光/交付时间。

独立 CPU 图像生成器覆盖标记宽度 30–100 px、子像素相位、大小、对比度和两种
背景。**192/192 个对照**的最大宽度误差为 **0.022718 px**，小于事先冻结的
0.5 px 预算；缺失、触边和多余标记三个负对照均被拒绝。这只资格化有限标靶
网格，不是现实相机或任意图像的统一误差上界。

## 运动与误差传播结果

六种条件分别为：无误差、轴向 +1 m、信息年龄 0.5 s、恒定尺度 1.1、
`k(t)=exp[0.12 sin(πt)]`，以及 +1 m 与 0.5 s 联合扰动。
延迟由显式早期目标状态注入，**没有测量系统本身的 0.5 秒延迟**。

预测为 `p=fWk/[Z(t−δ)+b]`；增长率比较使用 0.5 秒有限窗及每帧 `p±0.5 px`
传播出的测量区间。每个背景有 162 个主测量帧、126 个相互重叠的增长率窗口。
增长率与绝对宽度来自同一组图像测量，不能把两者计为独立证据。

| 观测 | 空背景 | scene-0383 静态背景 |
|---|---:|---:|
| 成功测到双标记 | 162/162 | 162/162 |
| 最大绝对投影残差 | 0.039824 px | 0.037305 px |
| 增长率预测落在测量区间 | 126/126 | 126/126 |
| 最大增长率残差 | 0.002712 s⁻¹ | 0.002191 s⁻¹ |
| 同进程重复最大 uint8 RGB 差 | 0 | 0 |

![运动成像结果](../../artifacts/motion_observation_probe_001/run001/mechanism_results.png)

恒定 10% 尺度偏差在场景背景下使实测间距比值落在 **1.09903–1.10079**，而
增长率基本保持原值。时变尺度则产生额外运动信息，本设计中增长率相对无误差
基线的最大偏移为 **0.338629 s⁻¹**。这个量与标靶参数和采样窗口绑定，不能
解读为 AD 反应或碰撞风险。

下面计数回答“若误以为没有注入误差，测量能否排除这个错误模型”。两个背景的
计数相同；每格分别是每背景的 27 帧或 21 个重叠窗口。

| 注入条件 | 绝对间距排除无误差模型 | 仅增长率排除无误差模型 |
|---|---:|---:|
| 无误差 | 0/27 | 0/21 |
| 距离 +1 m | 27/27 | 1/21 |
| 信息年龄 0.5 s | 27/27 | 4/21 |
| 恒定尺度 1.1 | 27/27 | 0/21 |
| 时变尺度 | 18/27 | 15/21 |
| 距离与信息年龄联合 | 27/27 | 5/21 |

**不能用增长率单指标替代绝对投影测量。** 时变尺度在部分采样时刻或差分窗口
与基线相等，所以不是每一帧都应当触发。距离/时间偏差的未排除也只是该窗口与
误差预算下区分力不足，不表示它们不改变信息。

## 参数识别和留出预测

仅用初始距离 24 m、接近速度 2/6 m/s 的联合扰动组估计共同 `b,δ`，然后保存
冻结参数，再渲染初始距离 28 m、4 m/s 的留出组。留出速度是内插，初始距离是
训练设置之外的组合；不能称为全面的速度/距离外推。

| 结果 | 空背景 | scene-0383 静态背景 |
|---|---:|---:|
| 距离偏差估计，实际注入 1 m | 0.993714 m | 0.995848 m |
| 信息年龄估计，实际注入 0.5 s | 0.501426 s | 0.500637 s |
| 距离参数区间 | [0.584066, 1.427377] m | [0.580490, 1.423759] m |
| 时间参数区间 | [0.408701, 0.591395] s | [0.409806, 0.592510] s |
| 留出中心预测最大残差 | 0.034418 px | 0.027080 px |
| 留出预测加测量区间覆盖 | 9/9 | 9/9 |

参数区间由 0.5 px 测量预算传播而来，是相关参数集合的投影，**不是统计置信
区间**。点估计很接近已知注入，不代表已经获得毫秒级现实测时精度。
留出组没有重新拟合；9/9 也不代表现实覆盖概率。

## 裁决与边界

| 主张或诊断 | 裁决 | 范围 |
|---|---|---|
| RGB 质心分析器通过已知标靶和指定负对照 | `accepted` | 192 个有限解析图像对照 |
| 已知标靶在 HUGSIM 渲染中遵守绝对投影与有限窗传播关系 | `accepted` | 两背景、三轨迹、六条件；324 帧 |
| 两速度识别可预测未参与拟合的速度/初始距离组合 | `accepted` | 已知尺寸/尺度、恒定 `b,δ`、18 个留出帧 |
| 同一进程内同输入渲染可重复 | `accepted` | 两背景 slow baseline 的局部重复 |
| 增长率单独足以检查绝对尺度准确性 | `rejected` | 10% 尺度变化是已测反例；诊断是指标构念不充分 |
| 旧 CF-M 车辆可直接套用精确宽度模型 | `down-weighted` | 缺少已资格化物理特征 |
| 整体 segment | `down-weighted` | 标靶测量不能自动转移到普通车辆、真实相机或驾驶任务 |

本轮未发现所测标靶渲染路径的合同违反。它主要排除了该网格中的投影/输入传播
错误，尚未检验学习得到的车辆表面、遮挡边缘、曝光、滚动快门、真实时钟调度、
AD 线索使用或近停动力学。两种背景仍共享 HUGSIM 渲染实现，不是两份独立现实
证据。既有 scene-0041、闭环及 matched factual 裁决均保持原样。

下一轮优先做**模型前提失效对照**：让同一已知标靶转动或非等深，比较简化
宽度公式与完整三维点投影，再遮住一个标记检查能否明确返回不可测。它的价值
在于确认何时不能使用本轮方法。普通车辆和现实相机的测量资格仍须另行建立。
