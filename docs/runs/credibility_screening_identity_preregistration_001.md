# 遮挡后标靶身份筛查 001：预注册

日期：2026-10-12。用户授权继续下一道基础题。本轮只验证受控遮挡后剩余标靶
身份，不开展新机制、真实数据扩充、自然车辆识别、AD 或 NuRec 工作。

## 独立身份与判定

[固定配置](../../configs/credibility_screening_identity_001.json)保留上一题的相机、
两个端点位置和尺寸。左靶的红通道在明暗图对中变化，右靶的蓝通道变化；
其他通道固定。身份来自 RGB 连通分量的差分通道质量比例，不由左右位置、
HUGSIM semantic、depth 或受测方提交的身份字段推断。

独立读图遍历整幅图，不用规定位置选 ROI。预定身份通道比例至少 **0.85**，
未达比例或未知编码保留 `identity=null`，标为 `measurement_unqualified`、
`tested=false`，不能计为已测身份错误。输入缺失／错时间同样不能伪装成检出。

预定位置预算仍为每端点每坐标 **0.25 px**，本轮须用带编码的新二维资格支持。
两靶都可见时检查编码身份、身份对应位置和 0.5 px 间距预算；只剩一靶时
检查身份及位置，完整间距必须保留 `null`。不补造隐藏端点。

## 有界执行与对照

1. 独立 CPU 资格：六种直接指定的单／双标靶与互换身份位置模板，横纵各两
   个相位、三种尺寸、两个背景及两种规定通道混合，共 **288 图对**。
   身份全部正确、位置和宽度均在预算内才可执行新 HUGSIM 渲染；另外验证
   红蓝模糊、未知绿色及边缘截断均不能强行给出合格身份。
2. 冻结配置、测量、正常／错误条件与代码 commit，再启动 GPU。
3. 孤立背景和 scene-0383 静态背景各执行：两靶可见；遮左靶只剩右靶；遮右
   靶只剩左靶。遮挡体位于目标前方 2 m，沿同一投影射线，sigma 0.45 m、
   opacity 0.9999；标靶 opacity 始终为 0.9。不是直接关闭标靶。
4. 两背景各构造两种错误输入：保持遮挡体、剩余位置和数量不变，仅互换
   标靶编码。共 **10 图对、20 张 RGB**。每个提交仍包含三个必测正常 case，
   错误对照只替换对应遮挡 case，其余图像保持不变。
5. 六个正常图对须通过。四个错误图对须仍通过旧数量／间距门，且可见点的
   不带身份位置仍正确，但因**已测身份矛盾**被新门拒绝。
6. 按实际下达的编码身份再检查全部提交，应正确；同射线对齐低于 `1e-9 px`，
   遮挡深度关系有效且不改变标靶 opacity。这一区分不把主动错误编码写成
   HUGSIM 自身身份或遮挡缺陷。

规则失败保留原结果，不能事后降低身份比例或放宽位置预算。窄合同通过也不
证明自然目标、部分遮挡、真实相机或智驾用途，整体仍为 `down-weighted`。
