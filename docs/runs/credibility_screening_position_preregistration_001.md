# 绝对投影位置筛查 001：预注册

日期：2026-10-12。用户授权逐题打磨基础筛查，本轮仅补两标靶的绝对位置，
不展开身份识别、机制参数识别、真实数据扩充或 AD 实验。

## 独立期望与规则

[固定配置](../../configs/credibility_screening_position_001.json)规定 CAM_FRONT、
800×450、完整 3×3 内参及相机坐标中的两个端点：
`(0.7, -0.65, 23.5)`、`(2.3, -0.65, 23.5)` m。
这是首次执行的新标靶位置，不把已使用的历史种子重新称为留出。

独立 CPU 针孔投影给出每个端点的 `u,v`；RGB 差分质心只读取明暗图对。
匹配按图像从左到右，不声称标靶语义身份已经验证。像素中心为列／行索引
加 0.5，与独立二维图和已检查的 gsplat 像素采样约定一致；不拟合坐标补偿。

新位置预算预先定为**每端点每坐标 0.25 px**。必须由本轮独立二维资格支持，
不能因为旧宽度预算为 0.5 px 就自动迁移。沿用宽度预算 0.5 px、差分阈值 8、
最小连通面积 3。两点必须同时可测，位置和间距均符合预算才通过。
缺图、错时间或不可读输入保留为未测，不能当作已测位置错误。

## 有界执行

1. CPU：三个直接给定的二维位置、横纵各四个亚像素相位、三种尺寸、黑色与
   独立纹理背景，共 **288 图对**。位置最大绝对误差须不超过 0.25 px，宽度
   最大误差不超过 0.5 px；资格失败则不启动 GPU，也不事后放宽预算。
2. 固定规则并记录 Git commit、配置与测量代码哈希，再执行新 HUGSIM 渲染。
3. 同一相机和位置，在孤立背景、scene-0383 静态背景各执行三个条件：正常，
   两点共同横移 +0.75 m，两点共同纵移 +0.50 m；共 **6 图对、12 张 RGB**。
   后两者以未改变的正常期望送测，专门资格化错误拒绝能力。
4. 正常两图对须通过新位置门；四个错误图对须因**已测位置矛盾**被拒绝，
   它们的间距须仍通过旧宽度门。不能把输入阻断计成成功检出。
5. 对全部六图对另按实际下达的端点位置裁决，须符合 0.25 px；相机—世界
   坐标往返须低于 `1e-5 m`。这一区分证明故障输入是主动错置，不冒充
   HUGSIM 自身放错标靶。

若正常主张失败，保留结果、拒绝相应有限主张，再隔离是测量、适配还是渲染
问题；不由一次失败直接宣布组件缺陷。通过仅支持本位置、两背景、点状标靶
合同。整体仍为 `down-weighted`，不升级普通车辆、现实相机或智驾用途。
