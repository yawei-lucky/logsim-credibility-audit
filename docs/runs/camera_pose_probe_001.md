# 固定世界标靶的相机位置与朝向检验

2026-10-30。整体证据：`down-weighted`。

相机位置和朝向改变后，固定世界标靶的 **44/44 个主图对**符合独立投影判据，
最大位置残差 **0.067993 px**，低于原 0.25 px 门。另有 **4/4 个孤立背景
等价路径对照**符合。本轮新增 48 图对、96 张 RGB，没有用新图校准或重新拟合。
这为“同一相对几何关系能处理观察者变化”增加了有限内部一致性证据。

## 真正改变了什么

[执行前合同](camera_pose_probe_preregistration_001.md)、配置和代码在 GPU 前
冻结于 `b2c4fe1ddef064cca7ef18ec2199ecc6cc70a442`，运行工作区干净。
两种标靶布局仍为原等高两点和倾斜不等深两点。每个布局的局部点和物体世界
位姿在全部主条件中保持不变，仅改变实际送入 HUGSIM 的相机位姿。

相机取原位、四种平移、四种朝向和两种位置朝向组合，共十一姿态；两个布局
和两个背景形成 44 个主图对。其中 4 个为原位锚点，40 个为相机变化条件。
保持原 CAM_FRONT 内参、尺寸、Gaussian 形状、编码、透明度及测量门限。
相机和物体的实际 GPU float32 矩阵逐例记录；每布局的主物体位姿仅一个
tensor 哈希，相机则有十一种，检查了标靶没有随相机一起移动。

设原相机坐标内的世界点为 q0，相机相对原位的旋转和平移为 R、t，预期为
q=R^T(q0−t)，再逐点针孔投影。参考按标量依次逆转三个角度；实际 HUGSIM
经 camera-to-world、物体到世界和渲染器 view matrix 路径生成 RGB。
输入预检和独立矩阵复算一致；没有读取 renderer 的投影点、深度或语义真值。

## 资格与主结果

二维仪器资格 768/768 图对身份正确，最大位置误差 0.090974 px、最大宽度
误差 0.173352 px；模糊、未知编码及截边对照均阻断。CPU 前置和主运行内
资格记录完全一致。四项相关实现检查通过。原门限保持每坐标 0.25 px、
宽度 0.5 px、身份编码比例 0.85。这是有限人工图样资格，不是实车误差界。

| 相机条件 | 符合完整逆变换规则 | 最大位置残差 |
|---|---:|---:|
| 原位锚点 | 4/4 | 0.062935 px |
| 只改位置 | 16/16 | 0.067993 px |
| 只改朝向 | 16/16 | 0.062729 px |
| 位置与朝向同时改变 | 8/8 | 0.047883 px |

全部主图对的两个编码点均可测，未发生背景遮挡或身份未知导致的未裁决。
最大误差发生于孤立背景、倾斜布局、相机前移 2 m 条件。没有调门或补系数。

## 两条执行路径与可辨识性

用 W0 表示原相机到世界变换，O 表示物体在原相机坐标中的位姿，A 表示
相机相对变化。主路径为相机 W0 A、物体 W0 O；对照路径为相机 W0、物体
W0 A^-1 O。两者给出的相对位姿都是 A^-1 O。对照仅在孤立背景的两个联合
条件和两个布局中执行，共四图对，不改变主路径的固定世界合同。

四个对照均符合独立投影的 0.25 px 门，最大位置残差 0.047883 px；两路径
读数差均为 0 px，符合事前保守 0.5 px 门。此处 0 表示保存图像的量化读数
相同，不表示物理误差为零。描述性复核还发现四对路径的对应 PNG 哈希均相同；
这不是跨条件、跨平台或一般渲染确定性主张。

这个结果还给出一个窄辨识边界：**相同的标靶图像位置，可以来自不同的世界
干预。** 仅凭这组位置读数不能区分移动相机和相应反向变换物体；需要世界状态
与干预记录。它支持用“相对位姿”作为可复用关系，同时提醒动作效应判断不能
只凭 RGB 位置。该对照共享同一独立几何参考，不增加现实真值来源。

## 复核、裁决与限制

96 张 PNG 哈希、48 份逐例保存记录和重新读数均一致。220 个主候选判定、
4 个对照绝对位置和 4 个两路径比较重新计算一致。运行前后期望清单哈希及
CPU 前置清单一致；全部记录的输入哈希通过。世界点在模拟器坐标中的输入
保持不变，实际 float32 位姿与标量预测的数值投影差最大 `1.08e-5 px`。
这些是输入、算术与保存记录检查，不是外部世界标定或物理精度。

有限仪器资格、固定世界下的相机成像一致性、孤立背景等价路径一致性为
`accepted`；上述竞争公式的全条件覆盖及“位置读数唯一确定干预来源”主张
为 `rejected`，每项都关联单独诊断。整体仍为 `down-weighted`。

只覆盖两个编码点布局、同一套内参和重建场景。这些是独立静态快照，尚未
检验连续相机运动、时间戳、移动遮挡或显露时刻；没有多相机同步、自然车辆
轮廓、控制动力学、AD、真实配对或完整机制字典资格。真实坐标来源缺口保留。
