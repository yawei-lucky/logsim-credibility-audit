# 停车任务指标盲区 001 — 执行前冻结

日期：2026-09-21。配置：`configs/stopping_metric_blindspot_001.json`。
本轮由用户授权执行；原 compact-conflict 待办暂缓，不修改任何历史裁决。

## 问题与范围

在一个可解析、非 HUGSIM 的参考系统中，检查**相同观测缺失量能否隐藏不同的
停车任务边界**，再检查最长缺失段、任务条件化确认时间分别排除了哪些歧义。
这不是模拟真实相机，也不把简化控制器称作 AD。HUGSIM、SparseDrive 和真实道路
的能力本轮不由该参考系统推断。它不是“现有全套审核都通过”的实验：当前仓库
本来就有时域、控制和外部资格 gate，且历史 detector 还记录 temporal IoU。

面板 V0 只审计已有“有检测帧数/总帧数”这类**边际摘要的充分性**，不复用 detector
或假造 RGB。来源例：`docs/hugsim_metric_evidence_map.md` §7 的 `16/37`、`2/37`。
V1（V0 + 最长缺失段）和 V2（V0 + 首次连续确认时间）为本轮新建候选工具，
不是 HUGSIM 自带指标，也不声称此前用过。

## 冻结系统合同

- 一维直道、静止障碍、自车无转向；初始间距为前保险杠至障碍平面的净距。
- 从 `t=0` 起每 `0.1 s` 收到一次二值目标可用性；共 12 帧，恰好 4 帧缺失。
  “可用”时信息正确；缺失不会被静默填充。全部枚举序列必须在窗口内完成确认，
  否则直接报告无完整参考，不以窗口末值外推。
- 控制器收到连续两帧有效观测后锁存制动请求；锁存后不会撤销。
- 请求经过固定执行器时延后以常减速度制动，速度下限为零；没有碰撞后动力学。
- 记录自由停车位置。越过障碍平面表示几何接触/越界，不表示模拟了碰撞力学。
- 设计点 `v=10 m/s, b=5 m/s², delay=0.1 s, gap=15.5 m`；包含正常无缺失对照、
  6 个预设模式和全部 `C(12,4)=495` 个模式的有限类覆盖。正常对照不计入 495。
- 零净距为接触边界，不能当安全样本；停止位置判据不使用 TTC 或纵向规划替代。

## 工具与参考的分离

审计器从观测序列求确认时间 `c`，解析预测边界：

`d* = v (c + delay) + v² / (2 b)`。

参考实现另外按事件推进观测、控制器和动力学，逐步积分至速度为零；不得调用
确认时间函数或停车距离公式。对 `0.02/0.01/0.005 s` 积分网格作小范围复验。
这构成计算路径交叉检查，**两者共享设计合同，不是两个独立现实来源**。

边界差异容限 `0.5 m` 只是本设计任务的示例容限，不是现实 AD 合格阈值。
数值复核容限 `1e-7 m`；几何零点容限 `1e-8 m`。

## 预先规定的比较

1. 以 dispersed 为参考，在同初始状态/同控制器下比较 V0/V1/V2 相同的模式：
   列出相同面板但边界差超容限的数目，以及在 `15.5 m` 处结果反转数目。
2. 记录各面板等价类的最小/最大停车边界：剩余世界是否仍有不同任务后果？
   枚举比例只描述该人工有限类，不解释为现实失效概率或统计置信区间。
3. 正常对照，以及 late_burst / late_dispersed：锁存后的缺失不应改变停车边界；
   避免把更大最长缺失段自动判成更严重任务偏差。
4. V2 假设的挑战：相同输入/相同确认时间，实际执行器时延从 `0.1` 变为 `0.3 s`。
   仅知道确认时间时能否误判？纳入 `[0.1,0.3] s` 的时延区间后应保留不确定性。

## 有限充分性命题（待本轮推导及核验，不是现实定理）

在上述合同且 `v,b,delay` 相同的模型对中，停车边界差等于 `v |c1-c2|`。
若确认时间误差上界为 `eta`，边界误差上界为 `v eta`；时延不确定还需传播进去。
只有停车余量与整个边界区间分离，才能在该模型类中给出稳健任务判断。
