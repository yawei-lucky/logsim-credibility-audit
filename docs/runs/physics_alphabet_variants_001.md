# 冻结成像规则的角度、深度与标靶布局检验

2026-10-30。整体证据：`down-weighted`。

同一套 R/T/P/V 规则在不使用新 RGB 校准、不重新拟合的情况下，与 **112/112
组新 HUGSIM 图对**的身份和位置读数相容；最大单坐标残差 **0.119408 px**，
低于原 0.25 px 门。这支持已给定规则在这批参数与局部布局变种中的复用。
它不是未知物理规律的发现，也没有验证普通车辆表面形状或驾驶任务。

## “不符合”是在拒绝哪一个主张

上一轮“交换旋转和平移顺序：单项 16/16，组合 0/32”指**候选预测**是否与
HUGSIM RGB 观测相容。0/32 表示该候选公式被组合试题排除，不是 HUGSIM 出现
32 项失效。HUGSIM 与完整规则是否相容，是另外一个主张；上一轮为 48/48。

在冻结坐标定义下，完整公式是 q=C0+d+R p，交换顺序的对照是 q=C0+R(d+p)。
只有 R 或只有 T 时，两者相同；二者同时存在时，差为 R d−d，一般不为零。
改变旋转中心或重新定义 d 可以得到其他等价写法，本试验不裁定全局唯一语法。

这里的“形状变种”仅指两编码点的局部布局，Gaussian 轮廓本身不变，尚不是
普通车辆网格、轮廓或材质变化。具体三维坐标见执行前合同。

为覆盖新投影尺寸与位置，二维资格网格事前扩至 768 图对，仍用原读数和门限。

|---|---:|---|

## 复核与结论边界

从保存 PNG 重新读取的 112 份观测与运行记录完全一致，224 张图片哈希通过。
672 个候选预测和判定重新计算一致；保存的期望与 CPU 前置运行也完全一致。
逐例保存记录、三维位姿往返、遮挡前后距离及射线关系均通过复核。齐次与标量
投影的最大差为 `1.14e-13 px`，仅是计算一致性，不是物理精度。
九项相关实现检查通过，其中四项为本轮新增。

有限读数资格和规则对本轮几何变种的内部预测一致性为 `accepted`。上述五个
竞争公式各存在有效读数下的矛盾，其“覆盖全部变种”主张为 `rejected`，机器
记录为每项保留独立诊断。整体仍为 `down-weighted`：同一相机、场景、编码点
和人为规定的几何不能资格化现实来源、自然物体身份、动态交互、AD 或任务安全。

本轮增加的是“字的参数与局部几何变化仍能用同一套语法解释”的有限证据。
规则由研究者提供，没有训练或从像素自动发现字典，也没有证明其唯一、最小
或完备。下一项应改变尚未验证的条件，避免继续累计相近的静态通过数。
