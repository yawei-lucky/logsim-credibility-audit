# 冻结成像规则的参数与标靶布局变种检验

2026-10-30。本地 Git 执行前合同，在本轮新 HUGSIM 图像生成前冻结；不是第三方
注册。按用户“固定规则，换角度、深度和目标形状继续做”的授权，检验已给定
R/T/P/V 规则的参数复用，不增加物理机制或重新拟合。

## 固定部分与解释

复用 [原实现](../../scripts/run_physics_alphabet_probe.py) 的 `camera_points`、
`project`、`predict`、`judge`、`render_pair`，原文件 SHA-256 固定为
`64b8c7645fd1b446230bcfce3d821ab334e3e0c800d356cdd369ff16d2f3a57b`。
实际保持局部点几何，把 R/T 写入物体位姿，经 HUGSIM 变换、成像。独立期望
仍为 q=C0+d+R p 后逐点投影与规定遮挡门。R 绕局部原点，d 用相机坐标表示。

相机、两背景、标靶 Gaussian 尺寸与透明度、颜色编码、遮挡体、读数器及
全部判题门保持原值：每坐标 0.25 px、宽度 0.5 px、身份编码比例至少 0.85。
换参数不等于改规律；所有期望在首张 RGB 前保存并记录哈希，后续不更新。

“交换顺序不符合”表示另一候选公式与观测矛盾，不是 HUGSIM 失效；完整规则
与 HUGSIM 是否相容另行判断。不得把排除解释的数量写成仿真器缺陷数量。

## 新输入

基准沿用原局部点 (-0.8,0,0)、(0.8,0,0) m、C0=(0,-0.65,24) m、角度 30°。
全部使用原 d=(2.4,0.35,-4) m。两个新角度为 -50°、55°；两个新基准深度为
18 m、36 m，平移后中心深度分别为 14 m、32 m。

两个新局部布局为：

- `wide_level`：(-1.1,0,0)、(1.1,0,0) m，改变跨度。
- `skew_depth`：(-0.9,-0.22,-0.15)、(0.7,0.25,0.25) m，改变高度、深度差及对称性。

这是两个编码点的局部几何变种，不是新车辆网格、实体表面轮廓或一般物体形状
资格。Gaussian 本身形状不变，应称“标靶布局迁移”。

分别只变角度、只变深度、只变布局，每类两个几何；再交叉两角度×两深度×
两布局，得到八个联合几何。合计 14 个。每个几何均测无挡、前置遮左、前置
遮右、后置左挡四种条件，两个背景各测一次：**112 图对、224 张新 RGB**。
前后遮挡体仍沿目标射线相差 2 m，标靶 opacity 保持 0.9。

输入预检用已知规则确认正深度、未截边和两点横向可分；不查看新渲染选题。
这些是设计覆盖，不能称独立现实样本或未知场景分布。

## 仪器前置资格

复用原二维资格器，只扩充事前指定的字面中心和尺寸网格：8 个模板×2 横向
相位×2 纵向相位×4 尺寸×2 背景×3 通道混合，共 768 图对。尺寸 sigma 为
0.6、0.9、1.3、1.9 px；另外保留模糊、未知绿色和截边负对照。此为有限格点
资格，不能推出所有中间图样的数学误差保证，更不是实车误差界。

新图只有在资格通过、输入有效、身份读数有效时才参与机制矛盾计数。未知或
无法读出的图对单列，不能当作排除了竞争解释。单靶不补造完整间距。

## 预测、判据与停止条件

本轮不用任何新单项 RGB 校准。不重复上一轮图像相加对照，以免增加新的测量
校准误差。固定六个已有公式：完整规则、顺序交换、去掉 R、去掉 T、固定共同
深度替代逐点透视、忽略 V。它们都由输入参数直接预测。

逐图对比较可见身份集合与每坐标误差。完整规则的迁移主张要求全部 112 图对
具备有效读数且符合原门；分角度、深度、布局、联合四组报告，不用平均掩盖
反例。任何失败保留原值，区分读数资格、V 前提和位置预测，不事后改门或补系数。

运行失败保留目录和 traceback；新运行另建目录，不覆盖成功或失败记录。
完整执行可以在存在预测矛盾时结束，但相应主张不得因进程完成而通过。
