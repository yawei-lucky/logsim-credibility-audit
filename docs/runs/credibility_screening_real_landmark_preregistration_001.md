# 真实图片路灯杆位置筛查预注册

日期：2026 年 10 月 13 日。本轮检查一个新真实短窗口中的路灯杆水平位置，
把 HUGSIM 新图像与事先冻结的图片参考对照。参考采用 Codex 目视候选区间，
没有人类标注资格或物理标定保证；本轮最高为 `down-weighted`，不能形成严格
同位姿真实等效结论。

## 固定选样与题目修订

在看本轮新 RGB 前，按已有真实清单最大帧号 102 后的前三个步长六时刻，
选定 CAM_FRONT 的 108、114、120，约 9.000521、9.500945、10.000825 s。
[选样记录](../../artifacts/credibility_screening_real_vehicle_001/selection_run001/selection.json)
保存原规则与来源哈希。仅提取三个官方归档成员，CRC、SHA-256、尺寸可核验。
它们仍属 scene-0383，不是新场景，也未证明是重建训练留出。

三张原图均无可辨认车辆，原定车辆位置题为未测，不作 HUGSIM 故障结论。
本次不继续搜索窗口以得到车辆正样本；保留同一窗口，将基础题收窄为三帧均
清楚可见的灰色金属路灯杆。此修订发生在真实图片检查之后、新仿真输出之前。

## 冻结的图片参考

[参考配置](../../configs/credibility_real_landmark_reference_001.json)记录原图哈希、
读数来源、模糊因素及两次只看真实 RGB 的 Codex 候选读数。它们共享图像来源，
不能当成两个现实真值投票；本轮没有人类专家复核。

观察量是像素行 `[200,240)` 内杆身**可见外轮廓的水平中点**，不是最暗竖条、
杆底、三维中心或邻近树干。冻结区间取两份真实图候选读数的保守包络：

| 帧 | 水平位置区间（px） |
|---|---|
| 108 | [104,114] |
| 114 | [199,210] |
| 120 | [304,315] |

这些区间只表达模糊、轻微倾斜和轮廓选择的不确定性。它们不是校准过的概率
误差界、任务容许误差或驾驶安全门，尤其不沿用人工标靶的 0.25 px。
仿真目标身份或轮廓无法确认时保留未知；不因结果移动参考区间或换观察量。

## 新 HUGSIM 图像与已知错误条件

[运行配置](../../configs/credibility_screening_real_landmark_001.json)及脚本在 GPU
启动前以 Git commit 冻结。三个时刻各仅渲染 CAM_FRONT，保留原生动态状态、
静态模型、分辨率和相机内参，共九张新 RGB：

1. `released`：发布 checkpoint 附带的相机记录，是声明配置的基本对照。
2. `source_init`：官方样本的初始相机记录，仅诊断元数据选择的影响。
3. `wrong_yaw`：在 `released` 基础上将前相机局部 Y 轴旋转 -5°；平移、内参、
   时刻、静态模型及原生动态姿态保持不变。这是主动错误视角对照，用于验证
   明显错位能否被挡住，不是 HUGSIM 自发产生的缺陷。

现有渲染器增加单相机选项，默认六相机行为保留。即使只读前相机 RGB，仍先
核验该时刻完整六相机元数据组、唯一记录及同步关系。

新图像产生后，记录同一杆身观察量的候选区间及完整图像；独立复核可采用只看
打乱顺序的渲染图、不给真实参考区间与条件名的 Codex 阅读。结果不等于人类
真值。若有分歧，取保守包络或未知，保留两份读数，不能选择更容易通过的一份。

## 判题与资格范围

判题器处理的是**附有图像证据的候选标注**，不假装自动识别自然路灯杆：

- 区间相交：此粗图片参考未排除该输入，`down-weighted`；不证明位置精确。
- 区间严格分离：已测候选标注位置矛盾，`rejected / tested=true`，记录最小
  间隔；不能直接推断物理相机或 HUGSIM 组件失效。
- 目标未知或声称缺失但缺失读数未资格化：保留未测，不能冒充已测位置矛盾。
- 缺图、哈希不符、错误时间、缺帧等：输入阻断，`tested=false`。

边界相接和未知保持、错误时间及图像哈希阻断须通过相关实现检查。预期三个
主动错视角图产生可辨认、与冻结参考分离的杆身区间；若读数未知或相交，保留
原结果，不把输入阻断计为检出。基本对照与样本初始记录均如实报告，不预设
真实等效通过，也不由观察到的差异定义新的门槛。

Source Availability Gate 仍未通过：原 nuScenes token、ASAP 转换映射、源数据
与 checkpoint 发布配对及训练留出不完整。初始与发布位姿有数值差，也有
坐标系统差异，不能将数值平移差直接写成实车相机误差。任何图像冲突首先是
此候选配对诊断，不能归因于某一个物理组件；本轮不运行 AD。
