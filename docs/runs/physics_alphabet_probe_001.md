# 成像机制字典与组合规则的 HUGSIM 实验

2026-10-29。整体证据：`down-weighted`。

本轮实际新增 **48 图对、96 张 HUGSIM RGB**。八种单项条件在两个背景中各
测一次，随后测十六种新组合。三个竞争写法都符合全部单项，但新组合只与
正确三维组合规则全部相容。此结果支持一种机制字典检验方法：既检查候选
操作是否需要，也检查它们怎样组合；它没有发现唯一或完备的世界基本字表。

## 本轮检验哪些字

[候选机制字典](../physical_mechanism_alphabet_001.md)将更广范围的候选分解为
相对几何、状态演化、相互作用、观测、信息时间及动作反馈。本轮只检验受控
成像范围内的四个操作：局部旋转 R、相对平移 T、逐点透视 P、给定透明度和
视线关系下的前后可见性 V。

R 和 T 可以合并成一个刚体位姿模块；本轮拆开是为了区分组合错误。“字”是
带输入、参数和适用条件的关系：T 的深度变化产生远近条件，横向变化产生
偏心条件，R 产生朝向变化，P 把它们共同变成像素位置和尺度，V 决定哪些
标靶还可测。无需为每个组合另写一条经验规则。

## 冻结和实际执行

[执行前合同](physics_alphabet_probe_preregistration_001.md)与
[配置](../../configs/physics_alphabet_probe_001.json)在 GPU 前冻结于 Git
`8ed4d9fa3d3fb90d5ee788e450503de45db9db78`，运行时工作区干净。
HUGSIM 为 `adeca402cad4af8635e13d0a105e2fee6a14de85`。

标靶的局部点坐标始终为 `(-0.8,0,0)`、`(0.8,0,0)` m。实际把旋转与平移
写入物体位姿，让 HUGSIM 渲染器将局部点变到世界，再通过相机成像；没有先
按预测结果变换点坐标来替代这条路径。相机与世界变换来自同一个发布记录。
独立预测用标量公式和针孔投影，RGB 读数只使用红／蓝差分编码及其质心。

设基准中心为 C0=(0,-0.65,24) m，局部点为 p，规定旋转 R、位移 d：

- 完整三维写法：q=C0+d+R p，再逐点投影和判断可见身份。
- 顺序写反：q=C0+R(d+p)，其余规则相同。
- 图像相加：从单项 RGB 取得各背景的像素效应，再使用
  uv(R,T)=uv(R,0)+uv(0,T)−uv(0,0)，组合阶段不重新拟合。

这里的顺序对错相对于冻结的坐标含义：R 绕物体局部中心，d 是相机坐标中的
位移。若改变旋转中心或重定义 d，可以得到其他等价写法；本轮不能证明一种
文字顺序是所有物理场景唯一的语法。

单项为基准、旋转 ±30°、两种三维位移、遮左、遮右和遮挡体后置。
组合为两种旋转 × 两种位移 × 四种遮挡条件。局部标靶形状、尺寸与相机
固定，两个背景为孤立与 scene-0383 静态背景，保留两者的独立读数。
相机前后遮挡体在目标射线上相差 2 m，标靶 opacity 保持 0.9。

CPU 仪器资格 432/432 图对身份正确，最大位置误差 **0.042835 px**；模糊、
未知编码和截边均阻断。GPU 前重复资格记录完全相同，预算保留事前每坐标
0.25 px。五项相关实现检查通过。这是有限人工标靶读数资格，不是实车误差界。

## 单项与组合结果

| 候选写法 | 单项符合冻结点预测合同 | 新组合符合冻结点预测合同 | 组合中的最大位置误差 |
|---|---:|---:|---:|
| 正确三维 R、T、P、V | 16/16 | 32/32 | 0.063665 px |
| 平移与旋转顺序写反 | 16/16 | 0/32 | 74.190728 px |
| 直接相加单项图像效应 | 16/16 | 2/32 | 2.246780 px |
| 去掉旋转 | 12/16 | 0/32 | 5.299947 px |
| 去掉平移 | 12/16 | 0/32 | 81.393081 px |
| 将透视改成固定深度 24 m | 8/16 | 0/32 | 18.382037 px |
| 忽略遮挡 | 12/16 | 16/32 | 其余 16 个为可见身份矛盾 |

完整规则在全部 48 图对内最大位置误差 **0.090563 px**，符合冻结预算。
四个删除／替代操作的版本各存在矛盾；说明这些项在本次候选表示和测试范围
里都承担可区分的作用，不能推论它们是唯一不可再分的基本物理定律。

![单项有三个相容写法 新组合只剩完整三维规则](../../artifacts/physics_alphabet_probe_001/analysis_run001/operator_compatibility.png)

最有辨识力的是顺序对照：只有 R 时 d=0，只有 T 时 R 为单位阵，两种写法
必然给出相同点位置。单项全部通过并不足以确定组合规则。新的组合在有效
RGB 读数下区分了它们，错误顺序的可见点误差为 **40.44–74.19 px**。
因此表中错序的“0/32 符合”指该候选预测与 RGB 观测矛盾、被试题排除；
不是 HUGSIM 有 32 项失效。实际 HUGSIM 输出与完整规则在这些条件下相容。

图像相加的单项效应来自测量，仍有 30/32 新组合位置矛盾；2/32 符合的结果
同样保留。透视作用于组合后的三维坐标，单项像素变化通常不能直接相加。
没有为其补系数，也没有把这些图对数当成现实错误检出率。

这里还需区分点预测器的评分与“真实单项效应可相加”这一机制主张。相加
使用三个有读数误差的校准量，组合本身又有一次读数误差。报告解释阶段追加
保守审计：若每项每坐标误差不超过 epsilon=0.25 px，相加假说允许的读数
残差为 4 epsilon=1 px，无需假定误差独立。仍有 **21/32** 组合超过此界，
其余 **11/32** 保留未确定；不能把这 11 个记为该机制已符合。
这是结果后的仪器误差审计，未改变原冻结点预测门或重拟合规则。
[审计记录](../../artifacts/physics_alphabet_probe_001/analysis_run001/image_additive_uncertainty_audit.json)
限定在本次有限仪器误差假设内，不能解释为实车误差界。

全部图对的读数均合格，没有将输入阻断或未知身份计作排错。二十个单靶图对
均保留完整间距 null。标靶几何与 opacity 保持不变；独立标量与齐次矩阵位置
往返最大差为 `4.44e-16 m`，仅说明计算链一致，不是物理精度。

## 得到了怎样的字典证据

有限的四操作规则可统一解释本轮单项和组合；只看单项仍有三个候选写法，
新组合将本轮七个候选程序中与全部读数相容的集合缩到一个。删项也为四个
候选操作提供了有限必要性证据。**基本关系的复用与组合规则都需要检验。**

本轮规则来自已知几何和研究者设计，选项空间也由研究者给定。没有从像素
自动发现未知因果变量或物理定律，不能排除候选类外的等效表示，也未证明
四个操作组成唯一最小字典。V 是规定的 Gaussian 透明度／尺寸与差分门下的
可见性合同，不是一般物体轮廓或完整不透明实体的光学定律。

有限的读数资格、完整规则的内部执行一致性、竞争写法矛盾为 `accepted`；
“单项通过足以确定组合规则”等强主张为 `rejected`，有单独诊断相连。
整体仍为 `down-weighted`。它没有验证自由运动、接触动力学、光照变化、时延、
真实车辆、AD 或任务安全。详情及拒绝上下文见[机器记录](physics_alphabet_probe_001.json)。

下一项有信息增益的检验，是保留当前规则，用新角度、深度或局部形状检验
字的参数／对象变种迁移；再逐项为时间演化或相互作用候选补独立参考。
不能用本轮通过替代真实来源资格，旧相机坐标与标注待办保留。
