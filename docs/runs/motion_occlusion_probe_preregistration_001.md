## 世界输入与逻辑时刻

固定 scene-0383 CAM_FRONT 及原内参，孤立和静态道路两个背景。标靶仍为
两个红／蓝编码 Gaussian 点，sigma=0.035 m、opacity=0.9，局部点改为
(-1.8,0,0)、(1.8,0,0) m，以保持遮挡一个点时另一个点明确可测。

目标中心 C(t)=(0,-0.65,26)+(0.3,0,-2)t m，绕局部 y 轴的角度为
theta(t)=-5+8t 度。独立点位置参考为 C(t)+R_y(theta(t))p，实际点保持局部
几何不变，把运动写入物体位姿交给 HUGSIM 变换和成像。每条从 0 到 2.2 s，
间隔 0.05 s，共 45 个完整逻辑时刻，无缺帧或尾部填充。

四条序列：规定运动无遮挡、早期前置遮挡、晚 0.5 s 的前置遮挡、早期后置
遮挡。遮挡体 sigma=0.2 m、opacity=0.9999、灰度 0.25；前置深度 16 m，
后置 34 m。它的基础中心沿左靶射线位于该深度，再叠加 x 方向的位移
sigma*s(t-phase)，其中 s 的折点为 (0,-6)、(0.4,0)、(1.0,0)、(1.4,6)，
折点间线性，范围外保持端值。目标与遮挡体均为规定的连续状态函数。

四序列×45 时刻×两背景，共 **360 图对、720 张新 RGB**。图对内不改变
标靶或遮挡体的 opacity、几何和位姿，只改变身份编码亮度。
camera.timestamp 与逐帧命令时刻一起记录，但这些是逻辑时间，未测真实
曝光、交付延迟或 HUGSIM 自身动力学更新。

## 三值参考和测量资格

不能把“有可见像素”直接等同“亮度中心仍是原三维点的投影”。部分遮挡
可以改变亮度中心。因此事前给每个点规定 clear、hidden、transition 三态。

无遮挡或遮挡体在目标后方为 clear。前置时，用独立点投影和各 Gaussian
投影尺寸界计算像素中心距离 d；尺寸界来自等 fx/fy 针孔 Jacobian 与当前
gsplat 的 eps2d=0.3 px²。若 d≤0.02*sigma_occluder_min，参考为 hidden；
若 d≥5*sigma_occluder_max+3*sigma_marker_max，参考为 clear；中间为
transition。它是针对本人工 alpha 轮廓和固定差分门的保守资格设计，不是
实体轮廓、材料完全不透明或普适光学定律。

GPU 前用独立二维 alpha 合成资格化：3 个标靶尺寸×2 个遮挡尺寸×2×2
亚像素相位×2 背景×前／后两种次序×4 个相对位置×2 通道混合，共 768
稳定图对。位置为 -6、0、0.02、6 倍遮挡 sigma。字面中心不读取 HUGSIM。
同时保留模糊、未知绿色和截边三项阻断；另存四个 ±0.75 sigma 的部分
遮挡读数诊断，不将它们的误差加入稳定样本通过率，也不据它们调门。

保持原每坐标 0.25 px、宽度 0.5 px、编码比例 0.85。已知 clear 点检查
位置及身份可测；已知 hidden 点应无该编码分量。transition 点不裁决位置
或存在性；若其余点明确可测，只保留其余点的结论。两点都 clear 时才输出
合格完整间距；单点或过渡带均保留 null，原始读数单独保存。

事前状态计数：两个前置序列每背景各 31 帧完全明确、14 帧含过渡点；无遮挡
与后置每背景各 45 帧完全明确。合计 **304 帧完全明确、56 帧含过渡点**；
664 项明确点检查中，612 项为 clear、52 项为 hidden。不得把 56 帧写成
全部已通过；实际读数未知时还须额外降级，不以输入阻断冒充机制检出。

## 时序与竞争解释

所有六个预测程序在首张新图前保存并哈希，不用新 RGB 校准：完整规则；
目标状态陈旧 0.2 s；遮挡体状态陈旧 0.5 s；忽略早晚干预相位；后置套用
前置遮挡规则；完全忽略遮挡。陈旧状态负时刻明确保持 t=0，仅作为竞争
预测，不是对真实数据填补。若真参考或候选自身为 transition，该点不参与
候选矛盾判定，避免用未资格化的部分轮廓拒绝解释。

事前独立消失区间分别为 (0,0.4] 和 (0.5,0.9] s；再显露区间分别为
(1.0,1.4] 和 (1.5,1.9] s。这是 clear 与 hidden 之间的保守逻辑采样包络。
记录实际第一次采样到的编码消失／再显露是否落入包络，不将其解释为精确
连续显露时刻。两种再显露包络分离，允许检验晚相位的再显露确实更晚；
不预设精确恢复 0.5 s 延迟，更不等于测出物理传感器延迟。

部分遮挡帧中的原始位置偏移，以及与同刻无遮挡控制的差，作为读数边界
诊断保存。任何偏移都不能直接裁定为 HUGSIM 投影缺陷；其独立二维对照和
资格前提需要分别解释。主判据不因诊断结果改变。

失败保留 traceback 和状态，重跑另建目录。保存版本、源码／输入哈希、
实际 GPU 位姿、时刻、RGB、全部读数、三值参考、逐程序判定和时序包络。
本轮仍限于规定运动下的成像与信息可测性；无 AD、原生动力学、严格现实
配对或完备字典主张。整体证据仍为 `down-weighted`。
