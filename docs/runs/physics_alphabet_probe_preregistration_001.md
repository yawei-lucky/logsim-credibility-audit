## 独立期望与新数据

固定 CAM_FRONT、800×450、scene-0383 发布相机和模型，两个背景。两标靶保持
局部坐标 `(-0.8,0,0)` 与 `(0.8,0,0)` m；基准中心 `C0=(0,-0.65,24)` m。
分别使用既有红／蓝差分身份读数和 0.25 px 单坐标预算，不按结果改门。

实际渲染保留局部点坐标，把旋转和平移放进物体位姿，经 HUGSIM 自身
`world = R_body_to_world * local + translation` 路径生成像素。独立预测用
标量公式 `q=C0+d+R*p` 后逐点针孔投影；禁止先按该预测变换局部点再当作
所谓的 HUGSIM 刚体变换测量。保存位姿、相机坐标往返和源码版本。

单项条件八个：基准、旋转 ±30°、两种平移 `(2.4,0.35,-4)` 与
`(-1.8,-0.3,4)` m、基准几何遮左、遮右、遮挡体放左靶后。
新组合为两种旋转 × 两种平移 × 四种遮挡条件（无／遮左／遮右／后置），
共十六个。每个背景依次先八个单项，再十六个组合；合计 **48 图对、96 RGB**。
这些是设计的同场景条件，不能当现实随机样本或训练场景留出。

遮挡体 sigma 0.45 m、opacity 0.9999，沿目标射线前／后 2 m；标靶 opacity
始终 0.9。“不可见”仅指低于规定差分门，不能推出完全不透射或自然物体遮挡
已获得资格。单靶不输出完整间距，模糊／未知编码保留未资格化。

## 七个竞争写法

- 完整规则：`C0+d+R*p`，逐点透视与前后遮挡门。
- 顺序写反：`C0+R*(d+p)`，其余规则相同。单项 R 或 T 数据中二者必然相同；
  组合数据才有判别力。这是竞争预测，不是主动把 HUGSIM 输入放错。
- 图像相加：只从该背景的单项 RGB 记录 `uv_R + uv_T - uv_base`，随后不再
  拟合，用于预测组合；沿用相同可见身份门。
- 去掉旋转；去掉平移；透视改成所有点固定使用基准深度 24 m；忽略遮挡。

先记录哪些程序符合全部单项，再用冻结的新组合排除竞争写法。完整程序应在
测量预算内；顺序写反预期可由组合区分；图像相加是否足够如实记录，不要求
每个组合都拒绝它。不因一个写法失败而新增系数修补。

不事后调预算。依据有限图对作有限主张，不汇总为总体可信分数。

规则来自已知几何知识及研究者设计；实验可以在该有限候选类中区分顺序与

在仓库目录、现有 HUGSIM 环境和 approved GPU-visible context 使用新输出路径：

```bash
/home/yawei/HUGSIM/.pixi/envs/default/bin/python \
  scripts/run_physics_alphabet_probe.py \
  --config configs/physics_alphabet_probe_001.json \
  --output artifacts/physics_alphabet_probe_001/NEW_RUN
```

单项图像效应、逐程序预测与读数、失败及汇总均保存于新的 `artifacts/` 目录。
