# 世界仿真条件的候选机制字典

这里的“字”指可反复实例化的**关系或机制**，不是固定场景名。比如“接近”
通常不是独立的字：相对运动改变距离，再经透视投影改变图像位置和尺度。
同一规则的参数变种与多条规则的组合，可以生成不同的测试条件。

用户在 2026-10-29 明确希望按这个角度设计并实验。这使本轮可以探索一个有限
机制字典。此前基本筛查、来源资格与旧证据保留；不据此宣布世界规律已被完整
分解。一个机制可以继续拆小，也可以与其他机制合并成更大的模块；“最基本”
必须相对于任务、表示精度和允许条件来定义。

## 候选的基本关系

| 候选机制 | 规定的关系 | 能生成的条件或变种 | 独立资格需要什么 |
|---|---|---|---|
| 相对几何与刚体变换 | 局部形状怎样随位置、朝向和尺度变换；物体相对相机的位姿 | 远近、左右、朝向、偏心；换观察位置 | 坐标与尺度参考、三维与图像对应 |
| 自由状态演化 | 当前状态和时间怎样决定后续位置、速度 | 接近、远离、匀速、加减速、转弯 | 完整时钟、实际状态轨迹、适用动力学 |
| 相互作用与约束 | 接触、力、路面约束怎样改变状态 | 碰撞、摩擦、制动、跟随中的物理约束 | 独立动力学与接触参考；意图规则另作行为模型 |
| 成像与可见性 | 三维关系怎样决定像素位置、尺度、遮挡及亮度 | 远小近大、部分遮挡、出视野、照明变化 | 传感器标定、RGB 读数资格、独立可见性参考 |
| 信息在时间中的传递 | 状态何时采集、何时交付、历史中保留什么 | 延迟、丢帧、多相机错时、陈旧输入 | 采集与交付时刻的独立记录 |
| 动作与反馈的闭合 | 指令怎样经执行器改变状态和下一次可获得的信息 | 转向避障、制动后观测变化、闭环失稳 | 指令到状态及反馈链的完整审计 |

这些是候选分解层次，不是六条已识别的基本物理定律。感知记忆、意图、路权与
行为选择也会影响智驾结果，应在明确的接收方或行为模型里表示，不能强行归为
普适物理规律。它们与上述物理、观测和时间机制共同构成具体测试合同。

已有 [Interaction Networks](https://arxiv.org/abs/1612.00222) 用对象状态与关系
组织物理预测，并报告在多个物理系统上的实验。这支持将关系作为建模对象，
没有给出我们这套世界仿真测试所需的完备字典。
[因果表示学习综述](https://arxiv.org/abs/2102.11107)也把从低层观测发现高层
因果变量列为问题。本轮给定了几何表示与候选规则，尚未解决该发现问题。

## 什么证据会使一个候选字值得保留

1. 先明确输入、输出、坐标系、保持量和适用条件；再检查同一机制在不同参数
   和情境中能否复用，不需要每个场景重新编一条规则。
2. 它与其他机制组合后仍能作事前预测，或能明确指出适用条件被违反。
3. 移除它会产生可区分的错误，恢复它能解释这些错误；不能只看拟合总分。
4. 测量能区分该机制与竞争解释。若不同写法在现有数据上相同，保留未知。
5. 与任务后果的关联另有证据。成像规则正确不自动证明 AD 或闭环可信。

“少量关系解释许多条件”是应检验的压缩与复用假设，不能单靠规则写得简短
判定成立。也不能因列出了物理名称就认定已经学出基本元素。

## 第一轮如何落地

先对成像子问题使用四个更细的操作：局部旋转 `R`、相对平移 `T`、逐点透视
投影 `P`、给定几何和透明度下的前后可见性 `V`。`R/T` 可合成一个刚体位姿
模块，`P/V` 属于观测模块；这种拆分是本轮用于排错的表示选择。

远近可通过改变 `T` 的深度分量生成；偏心通过横向分量生成；朝向通过 `R`
生成；朝向与偏心共同作用由 `P(T(R(p)))` 预测；前后遮挡再增加 `V`。
同一规则承担多个用例，不为每个场景单独规定答案。

首轮已用新 HUGSIM RGB 检查：单项试验能否区分规则写法；新组合是否需要正确
顺序；直接相加单项图像变化是否足够；删除某项后哪些条件失效。
计划与边界见[执行前合同](runs/physics_alphabet_probe_preregistration_001.md)，
结果另存[实验报告](runs/physics_alphabet_probe_001.md)。完整规则符合 16/16 单项
和 32/32 新组合；错误顺序符合全部单项却不符合任何组合；直接相加单项
像素效应只符合 2/32 组合。删项亦各有反例。这支持本次四操作表示与其组合
规则的有限复用，不是唯一字典或基本物理规律发现。

误差后，21/32 仍明确排除，11/32 保留未确定，不将校准误差当作机制缺陷。
